
# 🧠 AI Prompt Playground

An interactive Prompt Engineering application
built using Python and Streamlit.

## Features
- Zero-shot prompting
- Few-shot prompting
- Role-based prompting
- Prompt input interface

## Technologies
- Python
- Streamlit
- OpenAI API (planned)

## Run Locally

pip install -r requirements.txt

python -m streamlit run app.py
